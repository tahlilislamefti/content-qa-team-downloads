## Quick install

1. Download ZIP → **Extract All**.
2. Put the **Extension** folder in a permanent location.
3. In Google Chrome open `chrome://extensions`, enable **Developer mode**, and click **Load unpacked**.
4. Select the extracted **Extension** folder containing `manifest.json`.
5. Confirm ID `hklpmnbndociojhhmdddmhbohoacihac`. Pin the extension.
6. Open a permitted Google Doc, choose a project, and click **Audit Current Document**.

**Google access:** The ZIP is public, but the Google OAuth app is in Testing. Only Google accounts added to the team's **Test users** list may sign in (and the Docs/Sheets must be shared with them). This is a controlled internal pilot; test on another PC before wide rollout.

**Privacy:** This public build excludes the private client spreadsheet and built-in topical map. No personal data, OAuth tokens, passwords, or signing private keys are included. The `manifest.key` and OAuth Client ID are public identifiers.

The frozen v2.1.2 extension performs read-only SEO and content-structure checks. It does not edit source files, guarantee factual accuracy, or evaluate translation meaning. Updates for unpacked extensions are manual. No Chrome Web Store fee or AI API key is required.
